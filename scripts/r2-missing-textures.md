(served as `paints/<path after customization/>`). The newer kits below live in `items/assets/paintkits/**`,
which has not been exported. Export each file below as PNG (e.g. with Source2Viewer) and upload it to
`cs2-textures/paints/paintkits/<path after items/assets/paintkits/>` with a `.png` extension.
